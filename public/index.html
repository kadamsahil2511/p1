Four steps, one private link

From hello to briefing in minutes.

Bring your own Groq key. P1 checks it on a secure setup page, stores it encrypted, and asks you to confirm the account back inside WhatsApp.

01 / OPEN

Message P1

Open the chat and send /help to see the available workflow.

02 / REGISTER

Request access

Send /register. Your setup link is valid for ten minutes.

03 / CONNECT

Add your keys

Enter a primary Groq key and an optional backup on the secure page—never in chat. Create one in Groq Console ↗.

04 / CONFIRM

Finish in WhatsApp

Reply with /confirm <code>, then ask a question or run /latest.

Private by default

Your key. Your account. Clear boundaries.

P1 keeps setup out of the chat transcript and makes every sensitive step short-lived, validated, and explicit.

Encrypted at rest

Keys stay server-side.

Credentials are validated, encrypted, and activated only after confirmation from the matching WhatsApp account.

Short lived

Ten-minute setup links.

The private registration URL expires quickly and is tied to the requesting phone number.

Resilient

Optional backup key.

A separate key can take over only when the primary model request fails.

Transparent cost

No hidden inference bill.

Your Groq account controls usage, limits, and any provider charges.

User controlled

Delete from WhatsApp.

/deleteaccount removes the account and current conversation state.
