P1 is a WhatsApp assistant that chats with you and answers questions using a curated pool of technology articles. Each person brings their own Groq API key.

Open P1 in WhatsApp ↗How to start ↓

Get started in four steps

01 · OPEN CHAT

Message P1

Open the WhatsApp link above and send /help to see what the bot can do.

02 · REGISTER

Request a private link

Send /register. P1 replies with a setup link valid for ten minutes. Open it from your phone.

03 · ADD YOUR KEYS

Use the secure page

Enter a required primary Groq key and, if you want, a different backup key. Get a key from Groq Console. Never paste keys into WhatsApp chat.

04 · CONFIRM

Finish in WhatsApp

After the key check, P1 sends you a confirmation code. Reply with the exact /confirm <code> command. Then send an ordinary message or try /latest.

What you can do

Any message Chat normally with memory for your current session.

/latest Get recent sourced stories.

/ask <question> Ask about indexed articles.

/sources See the approved website pool.

/newchat Start a fresh conversation.

/account Check which keys are configured.

/deleteaccount Remove your account and current chat.

/help See the full command guide in WhatsApp.

Chats start a new session after one hour of inactivity. Source changes and the 07:00 IST digest are managed by the owner.

Your key, your account

The setup link is short lived and tied to your WhatsApp number. Keys are validated, encrypted on the server, and activated only after your WhatsApp confirmation. The backup key is used only if the primary model request fails. Your Groq account controls your usage and any provider charges.

Built with Mastra, Groq, Evolution API, FastAPI, MCP, and Qdrant. Code and architecture on GitHub.
